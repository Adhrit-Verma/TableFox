Read-only PostgreSQL for ChatGPT, Claude and any MCP client

Ask your PostgreSQL database anything. Read-only.

TableFox finds the few tables a question needs and runs guarded queries for your AI assistant. Your data never leaves read-only.

  • SELECT / WITH only
  • Two tool calls per question
  • Credentials never shown to the assistant

The problem

A full schema dump is mostly noise

Pasting every CREATE TABLE into a prompt costs tokens and buries the tables that matter. TableFox hands the model a small context pack instead.

How it works

Connect once. Then two calls per question.

2

Ask

Ask in plain English in your assistant. database_task_context ranks the relevant tables and their declared foreign-key joins into a small context pack.

database_task_context(
  "top products by revenue"
)
→ products, order_items, orders
→ 2 joins
3

Answer

database_readonly_batch runs up to five SELECT statements in one read-only transaction. Compact rows come back.

-- read-only transaction, 1 of 5
SELECT p.name,
  SUM(oi.quantity * oi.unit_price) AS revenue
FROM order_items oi
JOIN products p ON p.id = oi.product_id
GROUP BY p.name
ORDER BY revenue DESC LIMIT 5;

Safety

Read-only at every layer

Each guard works on its own. A request has to pass all of them before a single row is read.

  • SELECT and WITH onlyAny other statement type is rejected before it reaches the database.
  • Read-only transactions with timeoutsQueries run inside a read-only transaction and stop when the timeout is reached.
  • EXPLAIN before runningEach query is planned first, then executed.
  • Personal-data columns blockedColumns such as emails and passwords are not returned.
  • Read-only users onlyTableFox accepts only database users that cannot write.
  • Encrypted credentials, never shown to the assistantYou enter them on TableFox's own page. The assistant only sees query results.

FAQ

Questions

Does TableFox store my data?

No rows are indexed or cached. Your database credentials are stored encrypted.

Can it write to my database?

Never. Only SELECT and WITH statements run, inside read-only transactions, using a read-only database user.

Which databases does it support?

PostgreSQL databases reachable over SSL.

Is it open source?

Yes, MIT licensed. The code and developer guide are on GitHub, and you can run it yourself.

Which assistants work with TableFox?

Any MCP client: ChatGPT, Claude, Claude Code, Codex, Cursor, VS Code, Gemini CLI, Windsurf and more. See the setup guide.
